# Проект: anastasia_mogileva_project

## Статус
Свежий репозиторий. ТЗ и стек ещё не определены.

## Команда ролей (skills)

В проекте подключены 4 профильных скилла в `.claude/skills/`:

- **developer** — стандарты написания кода, тестов, безопасности
- **architect** — проектирование, ADR, контракты, риски
- **designer** — UI/UX, дизайн-система, a11y, работа с Figma
- **project-manager** — ТЗ, декомпозиция, приоритеты, риски

Используй роль, соответствующую задаче. Для крупных задач переключайся между ролями (PM → architect → designer → developer).

## Общие правила работы

1. **Язык общения** — русский. Технические термины можно оставлять как есть (PR, commit, deploy и т.д.).
2. **Перед началом задачи** — убедиться, что есть ТЗ или приёмочные критерии. Если нет — сначала роль PM.
3. **Перед написанием кода** — продумать архитектуру, если задача нетривиальная. Роль architect.
4. **Каждый коммит** — атомарный, с осмысленным сообщением, объясняющим «зачем».
5. **Никаких секретов в коде** — `.env`, ключи, пароли — только в `.env.local` (в `.gitignore`).
6. **Тесты** — обязательны для нетривиальной логики.
7. **Документация** — ADR для значимых архитектурных решений в `docs/adr/`.

## Ветки

- `main` — стабильная, защищённая
- `claude/*` — рабочие ветки Claude Code (текущая: `claude/setup-project-guidelines-WbBv1`)
- feature-ветки — `feat/<краткое-описание>`
- bugfix-ветки — `fix/<краткое-описание>`
