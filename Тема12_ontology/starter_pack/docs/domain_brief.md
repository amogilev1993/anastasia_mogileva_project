# Домен: Университетская академическая среда

## Краткое описание
Онтология описывает структуру университета: люди (студенты, преподаватели, административный персонал), учебные подразделения (факультеты, кафедры), образовательные ресурсы (курсы, аудитории), научная деятельность (публикации, проекты).

Цель — формальная семантическая модель, которая:
- поддерживает вывод по ролям (кто кого учит, кто чем руководит);
- даёт возможность проверять согласованность данных (например, у курса должен быть хотя бы один преподаватель);
- может использоваться для запросов вида «все студенты-магистранты кафедры X», «все курсы, которые читает профессор Y».

## Ключевые термины

| Термин | Определение |
|---|---|
| Person | Человек, связанный с университетом (общий супер-класс). |
| Student | Студент любой ступени обучения. |
| AcademicStaff | Преподавательский состав (профессора, лекторы). |
| AdministrativeStaff | Сотрудники, не ведущие учебные курсы. |
| AcademicUnit | Учебное подразделение (кафедра, факультет/школа). |
| Department | Кафедра — отвечает за курсы и преподавателей. |
| Faculty (School) | Факультет — объединяет кафедры. |
| Course | Учебный курс / дисциплина. |
| Publication | Научная публикация (статья / книга). |
| Project | Научно-исследовательский проект. |
| Room | Помещение (аудитория, лаборатория). |

## Допущения и границы

1. Один студент может одновременно быть зачислен на несколько курсов, но принадлежит ровно одной кафедре.
2. Курс предлагает ровно одна кафедра.
3. Профессор может руководить несколькими аспирантами, аспирант имеет одного научного руководителя.
4. Публикация имеет хотя бы одного автора, любой автор — это `Person`.
5. Email человека уникален — функциональное свойство.
6. Версия онтологии не охватывает: расписание (время занятий), оценки/успеваемость, финансы.

## Что считать правильным ответом

Онтология должна:
- содержать ≥15 классов (с иерархией глубины ≥3),
- ≥10 свойств (Object + Data),
- ≥20 индивидов,
- ≥5 ограничений (domain/range/cardinality/disjoint/functional),
- сохраняться в `.owl` и заново загружаться без ошибок,
- покрывать ≥5 competency questions из `kb/competency_questions.md`.
